3. Current → Target

S-004 — header values on the API path

Problem
Every schedule response echoed the target's credentials stored in action.headers.
Change
The output serializer masks values. The service swaps *** back to the stored value, matching names case-insensitively. *** with no stored value is a 422.
Wins
secrets never leave by read · read-edit-PATCH round trip is safe · OpenAPI schema unchanged
ADR: the merge rule is business logic, so it lives in schedule_service, not in the DTO or route.

S-005 — failure text on the fire path

Problem
Tenant payload and URL secrets reached logs, run records and a third-party notify host.
Change
Error text is built from method, scheme, host, port, path, exception type and HTTP status. Expected failures log at WARNING. Unexpected errors keep the traceback in the log, but the run records only Unexpected error: <Type>. Notify failures log the type only.
Wins
one place builds the error text · every downstream sink is clean without changes to jobs.py
